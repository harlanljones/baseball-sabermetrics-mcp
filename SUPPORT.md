# Support

For usage questions, check the [README](README.md), [MCP interface reference](docs/mcp-interface.md), and [data-source notes](docs/data-sources.md) first.

- Report a reproducible code defect with the bug report form.
- Request support for another CSV source with the data-source request form. Include upstream documentation and license links, not source data files.
- Use private reporting from [SECURITY.md](SECURITY.md) for vulnerabilities.

This project provides software only. It does not provide or license upstream baseball datasets and cannot resolve errors in source releases.
